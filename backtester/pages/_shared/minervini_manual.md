### ⚠️ Look-ahead(미래 참조) 방지 — 가장 중요한 규칙 3개

1. **가격 데이터는 기준일까지만 잘라서 본다.** 차트를 볼 때도 기준일 이후를 가리고 본다
   (TradingView는 특정 날짜로 이동 후 오른쪽을 안 보면 됨. 코드로는 `df[df.index <= 기준일]`).
2. **실적은 "발표일(reportDate)" 기준으로만 안다.** 분기 말일(fiscal date)이 아니라
   실제 발표일이 기준일보다 앞서는 분기까지만 사용. 발표일 데이터가 없으면
   보수적으로 `분기말 + 90일`을 발표일로 가정한다.
3. **애널리스트 추정치 상향(30일 전 대비) 항목은 과거 재현이 사실상 불가능하다**
   (추정치 스냅샷 히스토리는 유료 데이터). 과거 검증에서는 이 항목을
   "직전 분기 어닝 서프라이즈(+)로 대체"하고 체크리스트에 그렇게 표기한다.

## STAGE 0 — 시장 환경 (종목 보기 전에 먼저)

미너비니: 주도주는 시장보다 먼저 바닥을 떠나지만, 시장이 4단계(하락)일 때 신규 진입 승률은 급락한다.

| # | 항목 | 확인 데이터 | 통과 기준 |
|---|---|---|---|
| 0-1 | 지수 추세 **[자동, SPY+QQQ]** | 기준일까지의 SPY **와** QQQ 일봉 + 200일 SMA | **두 지수 모두** 종가 > 200일선, 그리고 200일선이 하락 중이 아님. 미너비니는 S&P 500만 보지 않고 나스닥 종합을 가장 자주 본다 — 성장주 유니버스면 나스닥 쪽이 먼저 꺾이는 경우가 많다 |
| 0-2 | 랠리의 질 **[자동, SPY+QQQ]** | 최근 25거래일 지수 일봉·거래량 | 상승일에 거래량 증가, 하락일에 거래량 감소. 분산일(−0.2%↑ 하락 + 거래량 증가일) **어느 한 지수라도 5회↑면 경고** (IBD 규칙 — 팔로스루/분산일은 S&P·나스닥 중 한쪽만 봐도 성립) |
| 0-3 | 신고가 > 신저가 | 유니버스(예: S&P500+Nasdaq100) 종목 중 기준일에 52주 신고가 5% 이내 종목 수 vs 신저가 5% 이내 종목 수 | 신고가 종목 수가 더 많음 |
| 0-4 | 강세장 초입 여부 (보너스) | 지수 저점 이후 경과 주수 | 새 강세장 첫 4~8주라면 최상의 기회의 창 — 이때 지수 저점일에 신고가를 찍었던 종목을 최우선 후보로 |

- 0-1, 0-2 실패 → 신규 매수 중단이 원칙 (관찰만).
- 수동 확인법: TradingView에서 기준일로 이동해 SPY·QQQ 주봉+200일선을 보면 1분. 44 스크리너는 0-1·0-2 실패 시 유니버스 스캔을 생략한다(토글).

## STAGE 1 — 추세 템플릿 8항목 (전부 통과해야 2단계 종목)

데이터: 기준일까지 **최소 260거래일**의 일봉 종가. 이평선은 모두 단순이동평균(SMA).

| # | 항목 | 계산식 (기준일 종가 = P) | 통과 기준 |
|---|---|---|---|
| 1-1 | 주가가 장기 이평선 위 | P vs SMA150, SMA200 | P > SMA150 **그리고** P > SMA200 |
| 1-2 | 이평선 정배열(하) | SMA150 vs SMA200 | SMA150 > SMA200 |
| 1-3 | 200일선 상승 | SMA200(오늘) vs SMA200(21거래일 전) | 최소 1개월 상승. **4~5개월(≈85~105거래일) 연속 상승이면 우량** |
| 1-4 | 이평선 정배열(상) | SMA50 vs SMA150, SMA200 | SMA50 > SMA150 **그리고** SMA50 > SMA200 |
| 1-5 | 주가가 50일선 위 | P vs SMA50 | P > SMA50 |
| 1-6 | 52주 신저가에서 충분히 이탈 | P / min(Low, 최근 252거래일) − 1 | **+30% 이상** (최고의 종목은 100~300% 위에서 나온다) |
| 1-7 | 52주 신고가에 근접 | P / max(High, 최근 252거래일) − 1 | **−25% 이내** (가까울수록 좋음, −15% 이내면 우량) |
| 1-8 | 상대강도(RS) 상위 | IBD RS 순위(1~99)가 원전 기준. 재현 프록시 = 가중 모멘텀 `2×(3개월 수익률) + 6개월 + 9개월 + 12개월 수익률`을 유니버스 전 종목에 대해 계산해 백분위 | **백분위 70 이상** (80~90대 선호). 유니버스 스캔이 어려우면 최소 조건: 3·6·12개월 수익률 모두 SPY보다 높고, 종가/SPY 비율(RS라인)이 최근 1개월 상승 중 |

- **8개 전부** 통과해야 다음 단계로. 하나라도 실패 = 탈락 (미너비니는 예외를 두지 않음).
- pandas 스니펫: `c = df["Close"]; sma = lambda n: c.rolling(n).mean().iloc[-1]`,
  52주 고저는 `df["High"].tail(252).max()` / `df["Low"].tail(252).min()`.

## STAGE 2 — 펀더멘털 (7~8장: 이익·매출·마진)

데이터: 발표일이 기준일 이전인 분기 실적만. YoY 증가율 = (금분기 − 전년동기) / |전년동기|.

| # | 항목 | 확인 데이터 | 통과 기준 |
|---|---|---|---|
| 2-1 | 분기 EPS 성장 | 최근 발표 분기 EPS YoY | **+20~25% 이상** (초고수익 종목은 +100% 이상도 흔함) |
| 2-2 | EPS 가속 | 최근 2~3분기 EPS YoY 증가율 나열 | 증가율이 분기마다 **커지는 중** (예: 엘란 +13→+80→+100→+120%) |
| 2-3 | 매출 동반 성장 | 최근 분기 매출 YoY | **+20% 이상** 또는 최근 2~3분기 가속 (F5: EPS 22→30→47→65% / 매출 2→15→34→46%) |
| 2-4 | 마진 개선 | 순이익률(netIncome/totalRevenue) 최근 2~3분기 | 전년 동기 대비 상승 추세 |
| 2-5 | 코드 33 (보너스) **[자동]** | 연간 EPS·매출·순이익률 4년치 (발표일 ≤ 기준일) | **3개 지표가 3년 연속 가속** (몬스터: EPS +75→+214→+195%, 매출 +20→+63→+93%, NPM 3.3→11.3→18%) — 충족 시 초고수익 최상급 후보. 실무 판정: EPS·매출은 YoY 3개 전부 + 이고 마지막 > 첫 해, 순이익률은 3년 연속 상승. 44 상세 표·45 자동 판정에 3개 지표별 표시 |
| 2-6 | 연간 EPS 박스권 돌파 (보너스) **[자동]** | 연간 EPS 5~7년 히스토리 | 수년 박스권·과거 고점을 새 연간(또는 후행 12개월) EPS가 돌파 (예: $0.18~0.32 4년 박스 → $1.32, +312%). 자동 판정 = 최신 연간 EPS > 0 이고 이전 3~7년 최고치 초과 |
| 2-7 | 어닝 서프라이즈 **[데이터 보조]** | 최근 발표 분기 epsActual vs epsEstimate. 티커+기준일이 있으면 체크리스트 밑에 Alpha Vantage 최근 4분기(발표일 ≤ 기준일) 실제/추정/서프라이즈와 연속 비트 횟수를 자동 표시. 링크 자동 생성: Zacks 어닝 히스토리 · Nasdaq 서프라이즈 · Yahoo 추정치 추이 · EDGAR 8-K | 실제 > 추정 (플러스 서프라이즈). *추정치 30일 상향 항목의 과거 대체물* |
| 2-8 | 가이던스 (수동) | 최근 실적 발표 보도자료·뉴스. EODHD 뉴스에서 기준일 −120일~기준일 가이던스 키워드 헤드라인을 자동 표시(과거일수록 커버리지 얇음). 링크 자동 생성: EDGAR 8-K(기준일 이전 제출분만, Ex.99.1이 보도자료) · 구글 뉴스 기간검색(기준일 −120일~기준일) · Seeking Alpha 실적 뉴스 | 상향 가이던스 동반이면 가점, **하향 가이던스는 즉시 탈락** |
| 2-9 | 재고·매출채권 적색경보 **[데이터 보조]** | 최근 분기 재무상태표: 완제품 재고 YoY, 매출채권 YoY vs 매출 YoY. Alpha Vantage BALANCE_SHEET(inventory·currentNetReceivables)로 자동 계산 — 단 '완제품' 세부 재고는 없어 총재고 기준 | 완제품 재고 증가율 ≫ 매출 증가율(예: +79% vs +11%)이면 **탈락**, 매출채권 > 매출도 경고 |
| 2-10 | 성장률 감속 경고 **[자동]** | 연간 EPS 증가율 최근 3개 | 뚜렷한 감속(델: 80→65→28%)이면 천장 신호 — 신규 진입 금지. 자동 판정 = YoY 두 번 연속 하락 + 마지막 < 첫 해의 ½ (44 '연간감속' 컬럼 ❗) |
| 2-11 | 턴어라운드 특례 | 적자→흑자 기업이면: 최근 2~3분기 영업이익 | 최소 2분기 연속 강한 증가 **또는** 1분기 만에 후행 12개월 EPS가 전 고점 근처/이상. 최근 2~3분기 증가율 > 직전 3~5년 평균. 마진이 고점 근처로 회복 중인지, 비용절감만으로 만든 이익인지 확인 |

- 필수 통과: 2-1 ~ 2-4 중 **3개 이상** + 적색경보(2-8 하향, 2-9, 2-10) **0개**.
- 수동 확인법: macrotrends → Revenue/EPS quarterly 표를 기준일 이전 발표분까지만 읽는다.

## STAGE 3 — 주도주·산업군 (9장)

| # | 항목 | 확인 데이터 | 통과 기준 |

| 3-4 | 산업군 내 위치 (수동) | 같은 산업군 종목들의 연초/6개월 수익률 비교 | 산업군 내 **상위 1~3위** (2등 기업까지만, 나머지는 후발주) |
| 3-5 | 산업군 자체의 강도 (수동) | 신고가 종목이 몰린 산업군 3~4개 (많으면 8~10개) | 해당 종목의 산업군이 그 안에 포함 |
| 3-6 | 기업의 신선함 (수동) | 상장일, 사업 성격 | 상장 10년 이내·신제품/신시장/신경영 등 "새로움"이 있으면 가점 (오닐 N) |
| 3-7 | 유동성·가격 | float, 평균 거래대금, 주가 | 주가 ≥ $10~12, 일평균 거래대금이 본인 포지션의 수십 배 이상 |

## STAGE 4 — VCP·진입 포인트 (10장: 여기가 타이밍의 전부)

데이터: 기준일까지 최근 12개월 일봉 차트(가격+거래량). 차트를 직접 보며 아래를 **자로 재듯** 측정한다.

| # | 항목 | 측정 방법 | 통과 기준 |
|---|---|---|---|
| 4-1 | 선행 상승 존재 | 베이스 시작 전 상승폭 | 베이스 이전에 뚜렷한 상승 추세(최소 +30%, 파워 플레이는 8주 내 +100%) |
| 4-2 | 베이스 기간 | 베이스 시작(고점)부터 기준일까지 주 수 | **3주 ~ 60주** (통상 5~26주). 3주 미만은 미성숙 |
| 4-3 | 베이스 깊이 | 베이스 내 고점→저점 낙폭 | **10~35%** 범위. **60% 이상 조정 종목은 무조건 탈락** |
| 4-4 | 축소 횟수 (T) | 베이스 안에서 고점→저점 조정 파동을 왼쪽부터 세기 | **2~6회** (대다수 셋업 2~4회) |
| 4-5 | 축소의 체감 | 각 조정 파동의 낙폭 %를 왼쪽부터 나열 | 각 축소가 **직전의 약 절반** (예: −25% → −15% → −8%, FSII: −18% → −5%) |
| 4-6 | 최종 축소 조밀함 | 마지막 축소(또는 손잡이/속임수 구간) 고저 낙폭 | **10% 미만** (속임수 구간 기준 5~10%). 3~5%면 최상 |
| 4-7 | 거래량 급감 | 마지막 축소 구간 평균 거래량 vs 50일 평균 거래량 | 뚜렷한 감소 (50일 평균 대비 −30% 이상 감소면 명확). "극도의 거래량 감소 + 조밀한 등락폭" = 매수 준비 완료 |
| 4-8 | 털어내기 (가점) | 베이스/손잡이에서 전저점 하회 후 빠른 복귀 여부 | 있으면 가점 — 매물 소진 증거 (DECK, VIVO 사례) |
| 4-9 | 손잡이 위치 | 손잡이(마지막 조밀 구간)의 수직 위치 | 베이스(컵) **상단 1/3**. 중간 이하에 있으면 '속임수(cheat)' 피봇으로 별도 취급 |
| 4-10 | 베이스 우측 급등 경계 | 베이스 오른쪽에서 피봇 없이 단기 급등했는지 | 급등 직후 추격 금지 — 재보합(핸들) 형성 대기 (MGA 사례) |
| 4-11 | 피봇 확정 | 마지막 축소 구간의 고점 = 매수 피봇 가격 | 피봇 가격을 숫자로 기록 |
| 4-12 | 돌파 확인 | 기준일(또는 다음 날) 주가가 피봇 상회 + 그날 거래량 | 피봇 돌파 **당일 거래량이 50일 평균의 +40~50% 이상** |
| 4-13 | 돌파 후 반응 (사후) | 돌파 후 눌림의 기간 | 정상 반응 = **1~7일 내 회복**하고 신고가 (테니스공 액션). 돌파가에서 −8% 이탈은 실패 |

- 4-1~4-7, 4-11~4-12가 필수. 통과 못 하면 "종목은 좋으나 **지금은 살 때가 아님**" — 워치리스트에 두고 피봇 형성 대기.
- 파워 플레이 특례: 8주 내 +100% 급등 후 **3~6주(최소 12일)** 좁은 횡보 → 펀더멘털 미비(2단계 일부 실패)여도 진입 허용되는 유일한 예외.

## STAGE 5 — 리스크·포지션 (진입 전에 숫자로 확정)

«Think & Trade Like a Champion»의 수학. 진입 전에 아래 4개 숫자를 기록해야 매수 자격이 생긴다.

| # | 항목 | 계산 | 기준 |
|---|---|---|---|
| 5-1 | 손절가 | 피봇(진입가) × (1 − 손절%) | 손절폭 **최대 10%, 기본 7~8% 이하**. 기술적 손절(베이스 저점)이 10%보다 멀면 포지션을 줄이지 말고 **진입을 포기** |
| 5-2 | 계좌 리스크 | 포지션 비중 × 손절폭 | 계좌 대비 **1.25~2.5%** (최근 성적 나쁘면 0.75~1.25%로 축소) |
| 5-3 | 포지션 비중 | 계좌 리스크 ÷ 손절폭 (예: 2% ÷ 8% = 25%) | 한 종목 **20~25% 상한**, 총 4~8종목 집중 |
| 5-4 | 손익비 | 기대 이익(예: 평균 익절 +20%) ÷ 손절폭 | **최소 2:1** |

매도 규칙(사후 관리용 — 검증 절차에서 청산 시점 판정에 사용):

- 이익 +20~25% 도달 시 강세에 매도(전량 또는 절반). 단, 돌파 후 **1~3주 만에 +20%** 도달한 종목은 8주 보유 규칙 적용(진짜 주도주 가능성).
- 손절 도달 시 무조건 청산 — 예외 없음.
- 절반 익절 후 나머지는 본전 스톱(무료 롤) → 50일선 종가 이탈(대량 거래) 시 청산.
- 천장 경고: 돌파 이후 최대 상승일·소진 갭·2~3주 내 +25~50% 클라이맥스, 연간 EPS 증가율 뚜렷한 감속.

## 3. 수동 백테스트 절차 — "그 시점에 정말 찾을 수 있었나 + 따랐으면 벌었나"

### 3-1. 검증 대상(종목, 기준일) 고르는 법 — 편향 방지가 핵심

두 그룹을 **반드시 같이** 검증한다. 슈퍼스톡만 고르면 생존 편향으로 아무 의미가 없다.

- **A그룹 (알려진 초고수익 종목의 돌파 시점)**: 과거 큰 시세를 낸 종목(예: NVDA 2016/2023, TSLA 2013/2020, MNST 2004, AAPL 2004, NFLX 2009, ELF 2023, SMCI 2023 …)의 **본격 상승 직전 베이스 돌파일**을 차트에서 찾아 기준일로 삼는다. → 체크리스트가 "진짜"를 통과시키는지 확인 (재현율).
- **B그룹 (무작위 대조군)**: 유니버스(S&P500+Nasdaq100 또는 러셀 성장주)에서 무작위 종목 × 무작위 기준일(2010~2024, 분기당 1개 등)을 뽑는다. → 체크리스트가 "아무거나"를 걸러내는지 확인 (정밀도). B그룹 대부분은 STAGE 1에서 탈락하는 게 정상이다.
- 실전형 제3방법 (신고가 리스트 재현): 특정 과거 날짜 하나를 정하고, 유니버스 전 종목 중 그날 52주 신고가 −15% 이내 & 추세 템플릿 통과 종목을 코드로 추린 뒤(이 레포 어댑터로 가능), 그 후보들만 STAGE 2~5를 수동 평가 — 미너비니가 실제로 매주 하는 루틴과 동일.

### 3-2. 시점별 평가 기록 (Streamlit 페이지의 기록 테이블과 동일 양식)

| 필드 | 내용 |
|---|---|
| 티커 / 기준일 | 예: MNST / 2004-03-15 |
| STAGE 0~5 통과 개수 | 예: 0단계 4/4, 1단계 8/8, 2단계 6/8, 3단계 5/7, 4단계 10/13, 5단계 4/4 |
| 최종 판정 | 매수 / 워치(피봇 대기) / 탈락 (탈락 사유 항목 번호) |
| 피봇가·손절가·포지션% | 4-11, 5-1, 5-3에서 기록한 숫자 |

### 3-3. 성과 측정 (기준일 이후 데이터를 이제야 연다)

1. **진입가** = 피봇 돌파가 (돌파일 종가로 근사, 슬리피지 +0.5% 가정).
2. 이후 일봉으로 **어느 쪽이 먼저인지** 확인: 손절(−8%) vs 익절(+20~25%) — 저가/고가 기준.
3. 기록: 1/3/6/12개월 수익률, 최대 상승폭(MFE), 최대 하락폭(MAE), 손절 히트 여부·날짜, 매도 규칙(50일선 이탈 등) 적용 시 청산일·수익률.
4. 이 레포로 하는 법: `fetch_ohlcv(ticker, 기준일, 기준일+1년)` 한 줄이면 됨. 수동으로는 TradingView에서 기준일 오른쪽을 다시 열어 확인.

### 3-4. 전략 판정 기준 (표본이 쌓인 뒤)

- 표본 **30건 이상**(A+B 합산) 모은 뒤: `통과(매수 판정) 그룹` vs `탈락 그룹`의 6개월 평균 수익률·승률·평균 MAE 비교.
- 기대 결과: 통과 그룹 승률 ≥ 40~50%, 평균 손익비 ≥ 2:1 (미너비니: 승률 50%±에 손익비 2~3:1이면 초고수익 가능).
- 통과 그룹이 탈락 그룹보다 낫지 않으면 → 어느 STAGE에서 변별력이 없는지 항목별 통과율 vs 성과 상관을 본다 (기록 테이블 CSV로 피벗).
- A그룹 재현율(진짜 슈퍼스톡 중 체크리스트 통과 비율)이 낮으면 기준이 너무 빡빡한 것, B그룹 통과율이 높으면 너무 느슨한 것.

### 3-5. 자주 하는 실수

- 기준일 이후 차트를 먼저 본 뒤 평가 (무의식적 확증편향) — **반드시 평가 기록을 끝내고** 오른쪽을 연다.
- 분기 실적을 분기 말일 기준으로 사용 (발표일 전에 알 수 없는 데이터) — reportDate 확인.
- 분할 미조정 가격으로 52주 고저 계산 — 조정가(adjusted) 사용.
- A그룹만 검증하고 "체크리스트가 잘 맞는다"고 결론 — B그룹 없이는 무의미.

## 4. 실전 워크플로우 — "2025-01-02에 살 종목을 어떻게 찾는가" (API 호출 단위)

기준일 D = 2025-01-02 라고 하자. 아래는 위 STAGE 0~5를 **전 종목 유니버스에 실제로 적용하는
깔때기(funnel)** 절차다. 각 단계마다: 무엇을 → 어떤 API로 → 어떤 기준으로 → 대략 몇 종목이 남는지.
API 키는 `secrets/secret.env`의 `EODHD_API_KEY` (컨테이너에 이미 주입됨).

### STEP 0. 유니버스 확보 — "나스닥/NYSE 전 종목 리스트"

```
GET https://eodhd.com/api/exchange-symbol-list/US?api_token={KEY}&fmt=json
```

- 반환: 미국 전체 심볼 (Code, Name, Exchange, Type). **필터**: `Type == "Common Stock"`,
  `Exchange ∈ {NASDAQ, NYSE}` → ETF/펀드/우선주 제거. 약 5,000~6,000종목.
- ⚠️ 생존 편향: 이 리스트는 **현재 상장 종목만**. 과거 기준일 검증에는
  `&delisted=1` 파라미터로 상장폐지 종목 리스트를 합쳐야 정확 (2025년처럼 최근이면 영향 작음,
  2015년 검증이면 필수).
- 레포 대안(대형주만): `data/adapters/wikipedia_universe.py` → S&P500 + Nasdaq-100 (~600종목).
  미너비니 종목은 중소형에서 많이 나오므로 **본검증은 전체 리스트 권장**, 연습은 대형주로.

### STEP 1. 1차 가격 프리필터 — "그날 하루치 벌크 시세로 싸구려·저유동성 제거"

```
GET https://eodhd.com/api/eod-bulk-last-day/US?api_token={KEY}&date=2025-01-02&fmt=json
```

- 전 종목의 D일 OHLCV가 **한 번의 호출**로 옴 (쿼터는 벌크라 ~100콜로 계산됨).
- 필터: 종가 ≥ **$10~12**, 거래대금(종가×거래량) ≥ **$5M/일** (STAGE 3-7).
- 남는 규모: ~1,500–2,500종목.

### STEP 2. 추세 템플릿 기계 스크린 (STAGE 1의 1-1~1-7)

생존 종목마다 D까지 약 300거래일 일봉을 받는다 (종목당 1콜, 캐시 필수):

```
GET https://eodhd.com/api/eod/{SYM}.US?api_token={KEY}&from=2023-10-01&to=2025-01-02&period=d&fmt=json
```

- 레포로 하면 캐시가 공짜로 붙는다:
  `CachedMarketDataAdapter(EODHDAdapter()).fetch_ohlcv(sym, date(2023,10,1), date(2025,1,2))`
  → 두 번째 실행부터 파퀘 캐시라 API 호출 0.
- 각 종목에서 계산: SMA50/150/200, 200일선 21거래일 전 대비, 52주 고저 대비 위치
  → **1-1~1-7 일곱 개 전부 참**인 종목만 통과.
- 남는 규모: 시장이 상승장이면 ~200–500, 약세장이면 수십 개.

### STEP 3. RS 백분위 (1-8)

- STEP 2에서 이미 받은 일봉으로 종목마다 `모멘텀 = 2×(3개월 수익률) + 6개월 + 9개월 + 12개월`.
- **유니버스 전체에서 백분위** 계산 → **상위 30%(백분위 ≥ 70)**만 통과. 추가 API 호출 없음.
- 남는 규모: ~100–250.

### STEP 4. 펀더멘털 — "EPS 증가 중인지" 종목별 확인 (STAGE 2)

> ⚠️ **이 레포 기준 (2026-09 확인)**: 현재 EODHD 플랜에는 Fundamentals API가 없다(HTTP 403).
> 기본 소스는 **Alpha Vantage** (`ALPHAVANTAGE_API_KEY` 보유, EPS는 1996년까지 발표일 포함
> 풀 히스토리, 매출은 ~2006년부터). 어댑터: `data/adapters/alphavantage_growth_fundamentals.py`
> (EODHD 버전도 `eodhd_growth_fundamentals.py`로 있음 — 플랜 업그레이드 시 자동 체인).
>
> ```
> GET https://www.alphavantage.co/query?function=EARNINGS&symbol={SYM}&apikey={KEY}
>     → quarterlyEarnings: {fiscalDateEnding, reportedDate, reportedEPS, estimatedEPS}
> GET https://www.alphavantage.co/query?function=INCOME_STATEMENT&symbol={SYM}&apikey={KEY}
>     → quarterlyReports: {fiscalDateEnding, totalRevenue, netIncome}
> GET https://www.alphavantage.co/query?function=OVERVIEW&symbol={SYM}&apikey={KEY}
>     → Sector / Industry
> ```

EODHD 플랜에 fundamentals가 있으면 한 방에 다 나온다:

```
GET https://eodhd.com/api/fundamentals/{SYM}.US?api_token={KEY}&fmt=json
```

⚠️ 이 엔드포인트는 **요청 1건 = API 쿼터 10콜** 소모(AV는 티커당 3콜). 150종목이면 1,500콜 —
플랜 쿼터 안에서 여유 있지만, 반드시 STEP 2·3 통과 종목에만 쏜다.

payload에서 보는 곳 (전부 **발표일 ≤ D 필터** — look-ahead 방지):

| 체크 항목 | payload 경로 | 판정 |
|---|---|---|
| 2-1 분기 EPS YoY | `Earnings::History` → 각 분기 `{date, reportDate, epsActual, epsEstimate}` | `reportDate ≤ 2025-01-02`인 최신 분기의 epsActual을 4분기 전과 비교, **YoY ≥ +25%** |
| 2-2 가속 | 같은 곳, 최근 3개 발표 분기 | YoY가 분기마다 커지는지 |
| 2-7 서프라이즈 | 같은 곳 | `epsActual > epsEstimate` |
| 2-3 매출 YoY·가속 | `Financials::Income_Statement::quarterly` → `{date, filing_date, totalRevenue}` | `filing_date ≤ D` 분기만, YoY ≥ +20% 또는 가속 |
| 2-4 순이익률 | 같은 곳 `netIncome / totalRevenue` | 전년 동기 대비 상승 |
| 2-5 코드33 · 2-6 · 2-10 | Alpha Vantage `annualEarnings` / `annualReports` 4~7년치 (연간 발표일 = 같은 회계연도 Q4 `reportedDate`) | 코드33 3지표 각각 · EPS 신고 · 급감속 경고 — 자동 |
| 2-9 재고·채권 | `Financials::Balance_Sheet::quarterly` → `inventory`, `netReceivables` | 재고·채권 YoY ≫ 매출 YoY면 탈락 |
| 섹터/산업군 (STEP 5용) | `General::Sector`, `General::Industry` | 저장해둔다 |

- 판정: 2-1~2-4 중 3개 이상 + 적색경보 0개.
- 남는 규모: ~20–80.
- 수동 대안(몇 종목만 볼 때): macrotrends.net → 티커 → Revenue/EPS quarterly 표를
  D 이전 발표분까지만 읽기. stockanalysis.com도 동일.

### STEP 5. 산업군 집계 — 주도 그룹 확인 (STAGE 3)

- STEP 4에서 저장한 `Industry`별로 생존 종목 수를 센다 → **생존자가 몰린 3~4개 산업군**이 주도 그룹.
- 각 그룹 안에서 RS(STEP 3 값) 순위 **1~2위만** 남긴다 (3등 이하는 후발주).
- 지수 대비 체크(3-1~3-3): SPY 일봉 1콜 받아 직전 조정 구간의 종목 vs 지수 낙폭 비교,
  낙폭이 지수의 2~3배면 탈락.
- 남는 규모: **~10–30 = 정밀 관찰 후보군.** 여기까지는 전부 기계적 — 코드/스프레드시트로 가능.

### STEP 6. 차트 눈 판독 — VCP·피봇 (STAGE 4, 여기서부터 수동)

- 후보마다 D까지 12개월 차트(가격+거래량)를 열고 — **D 오른쪽은 가린다** —
  STAGE 4 체크리스트(베이스 기간·깊이·축소 횟수·최종 조밀·거래량 급감)를 측정.
- **피봇이 이미 형성됐고 현재가가 피봇 −5% 이내** → 오늘의 매수 후보.
  베이스는 좋은데 피봇 미형성 → 워치리스트 (다음 날 다시 확인).
- 남는 규모: 매수 후보 ~3–10, 워치 ~10–20.

### STEP 7. 진입 숫자 + 기록 (STAGE 5)

- 후보마다 피봇가·손절가(≤8%)·포지션(계좌리스크 1.25~2.5% ÷ 손절폭, 상한 25%) 확정.
- `43_Minervini_Checklist` 페이지에 종목·기준일별로 체크 결과와 숫자를 기록 → CSV 누적.
- 이후 (평가 저장 뒤에만) D 이후 데이터를 열어 §3-3 성과 측정.

### 자동화 현황 (2026-09)

STEP 0~5는 **`44_Minervini_Screener` 페이지**로 자동화됐다 — 기준일 하나 넣으면
유니버스 → 추세 템플릿 → RS 백분위 → 분기 EPS·매출(발표일 point-in-time) → 산업군 →
피봇/손절선/익절선까지 뽑고, 옵션으로 기준일 이후 돌파/손절/익절 시뮬레이션도 표시한다.
피봇은 **VCP 구조 기반 정밀 계산**: 4% zigzag 스윙으로 베이스 안의 축소(T) 파동을 실측해
4-2(베이스 주 수)·4-3(깊이)·4-4(횟수)·4-5(체감)를 자동 판정하고, 피봇 = 마지막 축소의 천장
(`contraction-high`) 또는 그 아래 6% 이내로 뭉친 선반의 고가(`tight-shelf(cheat)` — 속임수 피봇).
4%+ 눌림이 없는 직선 랠리는 "압축 없음 — 추격 금지"로 표시된다 (폴백: 최근 N일 고가).
STEP 6 최종 확정(눈 판독)은 여전히 수동 — 43번 체크리스트 페이지에서.
판정 로직: `strategy/adapters/minervini_screener.py` (테스트: `tests/test_minervini_screener.py`).
