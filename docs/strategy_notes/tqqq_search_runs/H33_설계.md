# H33 — 사다리 + 월말 재진입(전 구간, 라벨 없음) 설계 (2026-11-11, 코드 작성 전)

## 가설 한 줄
스위치 18 의 이탈은 매일, 20일선 **재진입은 그 달 마지막 거래일에만**, 사다리(50/65/80 ⅓) 는 어느 날이든. 닷컴 2001~02 의 왕복(재진입이 만든다) 을 라벨 없이 끊고, 느린 재진입이 놓치는 V자(2020-04·2023-01) 는 사다리 매수가 받는지. 레짐 라벨이 없으니 라벨 플라세보 문제가 없다(런 셔플만).

## 그리드 (6 조합)
사다리 {50/65/80 ⅓, 40/55/70 ⅓} × 재진입 {월말만} = 2 + 이탈도 월말 {같은 두 사다리} = 2 + 사다리 없이 월말 재진입만(대조, H14 L60 과 비슷) 1 + 사다리 50/65/80 + 매일 재진입(= R46, 대조) 1. G6 이웃: 사다리 교체·이탈 주기 토글.

## 예상 함정
- 2018-12 이탈 뒤 사다리 1/3 만 들고 2019-01 말까지 재진입 못 함(TQQQ +25% 놓침의 2/3).
- 2020-03: 사다리로 2/3 들어가고 월말(03-31) 재진입 — 20일선 재진입(04-06) 보다 오히려 빠를 수 있음.

## 어느 관문에서 떨어질까
G1(2018·2019 류 짧은 조정에서의 지연) 또는 G4.
