# H13 — 한국 세제 정밀 모델을 공용 평가기에 (2026-11-10, 도구 · 코드 작성 전)

## 무엇을 넣나
딥리서치 남은 질문 3: 연 250만원 공제 · 연도 간 손실 이월 없음 · 배당소득세 15.4%.
- **이미 있는 것**(확인): `leveraged_etf_lab._Ledger` 는 연말에 `max(0, 실현손익 − 250만) × 22%` 를 내고 실현손익을 0 으로 되돌린다 → 연 통산·공제·이월 없음 전부 구현돼 있다. 점검: 2020 −10M 실현 뒤 2021 +10M 이면 2021 에 (10M − 2.5M)×22% = 1.65M 과세(이월 환급 없음) → 최종 0.9835 로 확인.
- **없는 것**: 배당세. 가격은 yfinance `auto_adjust=True`(배당 세전 재투자) 라 배당에 붙는 15.4% 가 빠져 있다 → 보유 평가액 × 연 배당수익률 × 15.4% / 252 를 매일 현금에서 차감(세금으로 집계). 배당수익률 가정(연): TQQQ 0.7%, QQQ 0.6%, QLD 0.3%, SOXX 0.8%, 금 0, 1× 종목 리스트 1.2%.

## 설계
- `CostParams` 에 `dividend_yield`(기본 0)·`dividend_tax_rate`(0.154) 추가. `simulate_exposure`·`simulate_weights` 가 드래그를 적용(다자산은 `dividend_yields` dict 로 열별).
- `tqqq_gates.GATE_COSTS` 는 **그대로**(지금까지의 바퀴와 비교 가능하게), `GATE_COSTS_KR` + `DIVIDEND_YIELDS` 를 추가하고 CLI cfg `"tax_model": "kr"` 로 선택. 기준선 TQQQ 세후(마지막 한 번, 배당세 없음) 는 재계산하지 않는다(§4) — 배당세는 전략 쪽에만 붙어 전략에 불리하다(유리한 쪽을 기준선에).
- 자체 검증: 보유·스위치 18 을 kr 모델로 다시 돌려 기본 모델과의 차이(비율 중앙·MDD) 를 기록. 예상: 연 0.1%p 드래그 → 10년 비율 −0.01 안팎, 판정 불변.
- 시도 수에 안 센다(도구).
