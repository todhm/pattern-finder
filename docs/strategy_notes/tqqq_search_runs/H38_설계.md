# H38 — 스티치의 긴 약세장 깊이 35/40% (2026-11-11, 코드 작성 전; R48 후속)

## 가설 한 줄
R48 의 라벨 플라세보 탈락은 A 표본의 유일한 긴 약세장(2022) 을 월말 판정으로 돌린 비용 때문. R-C 를 "낙폭 ≥ 35% / 40%"(체류 120일 경로는 끄거나 유지) 로 엄격히 정의하면 2022(QQQ 최대 낙폭 −35% 안팎) 가 라벨에서 빠지거나 늦게 들어가 A 의 비용이 사라지고, 닷컴(−83%)·2008(−53%) 은 그대로 잡혀 B 가 지켜지는지 — 라벨 플라세보가 구조적으로 통과 가능해지는 유일한 길. 이것은 "긴 약세장" 의 정의 손잡이이고 G6(depth 30/35/40 이웃) 로 판정한다.

## 그리드 (5 조합)
(depth, 체류 경로) ∈ {(0.35, 120일 유지), (0.35, 체류 경로 끔), (0.40, 120일 유지), (0.40, 끔)} + 기준 (0.30, 120일). R-C 부품 = 월말 스위치 18, 그 외 = 스위치 18 + 사다리 50/65/80 ⅓. 플라세보: 런 셔플·라벨 셔플, 둘 중 낮은 쪽. G6 이웃: depth 인접·체류 경로 토글.

## 예상 함정
- 체류 경로를 유지하면 2022 는 어차피 2022-07(120일) 에 C 가 된다 → 변화 없음. 끄면 2008(−53%) 은 잡히지만 2000 은 −40% 에 2000-12 에야 → 닷컴 첫 해 왕복이 남아 B 최악 창이 나빠질 수 있다.
- 2022 가 빠지면 "2022 를 피하지 않은" 것이므로 A-∞ 는 사다리 단독(1.75) 으로 돌아가고 라벨 플라세보는 ≈50% 근처(차이 없음) 가 되어 95% 는 여전히 못 넘을 수 있다 — 그 경우 라벨 플라세보는 "A 에서 R-C 가 하는 일이 없다" 를 말할 뿐이며, 이 구조에서는 95% 가 원리상 불가능하다는 결론으로 기록한다.

## 어느 관문에서 떨어질까
G4(체류 경로 끔) 또는 G5 라벨.
