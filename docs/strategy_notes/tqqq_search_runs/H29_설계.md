# H29 — 사다리 + 긴 약세장 게이트 설계 (2026-11-11, 코드 작성 전; R46 후속)

## 가설 한 줄
R46 사다리(50/65/80 ⅓) 의 유일한 G4 탈락 원인은 닷컴(1999~2000 시작 창) 에서 사다리가 소진된 뒤 −99% 까지 더 떨어지는 것. **확인된 긴 약세장** 동안은 사다리 매수를 막거나 절반으로 줄여 그 창을 지키고, 2020-03(긴 약세장 아님) 의 사다리 매수는 유지한다. 2022-10 의 매수는 잃는 교환.

## 데이터·point-in-time
