# H23 — 워크포워드 전략 선택(규칙 로테이션) 설계 (2026-11-10 저녁, 코드 작성 전)

## 가설 한 줄
전략 라이브러리(보유·스위치 18·스위치 24·월말 스위치 18·QLD+스위치 18·vt60+스위치 18·스위치 18+패턴(≥10%)) 중 **직전 N년(3/5) 에서 세후 성적이 가장 좋았던 것**을 매 분기 첫 거래일에 골라 다음 분기에 쓴다 — 과거만 본다. 다른 점: R14 는 자산 로테이션, R35(슬롯) 는 레짐 라벨 기반 고정 지도, 이것은 **성적 기반 규칙 로테이션**. 사용자 지시("시점마다 맞는 전략을 이어 붙이기") 의 동적 판.

## 데이터·point-in-time
H0 와 같은 가격·비용. 직전 N년 성적은 분기 시작 전날까지의 구간을 자본 1 로 새로 돌린 세후 배수(같은 비용) — 전부 과거 자료. 선택 규칙 적용은 다음 거래일부터(원장 lag). QLD 는 H11 스플라이스.

## 그리드 (8 조합)
N {3, 5}년 × 성적 척도 {세후 배수, 세후 배수 ÷ |MDD| (Calmar 류)} × 교체 규칙 {즉시, 끈적(현재 것보다 10% 이상 나을 때만 교체)} = 8. 조합당 ≈ 1~2분(분기 134 × 부품 7 × 과거 구간 시뮬).
G6 이웃: N 토글·척도 토글. 플라세보: 분기마다 라이브러리에서 무작위 선택 30 seed(창별 비율 중앙).

## 예상 함정
- 선택 지연: 2010~2014 시작 창은 2008 포함 과거 성적으로 고르므로 스위치·QLD 류를 들고 2010년대 초 상승을 덜 먹는다 → G1.
- 라이브러리가 전부 "보유 ≤ 1.0 근처" 라 어떤 선택도 보유를 크게 못 넘고, 교체 때마다 세금.

## 어느 관문에서 떨어질까
G1 (중앙 < 1.0). Calmar 척도는 MDD 가 좋은 QLD·월말을 골라 더 낮을 것.
