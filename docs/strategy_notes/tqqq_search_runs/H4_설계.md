# H4 — 변동성 타기팅 TQQQ 비중 + 나머지 QQQ (+ 스위치 18) 설계 (2026-11-10, 코드 작성 전)

## 가설 한 줄
TQQQ 비중 w = clip(목표σ / 예측σ(TQQQ), 0, 1) 로 매일 맞추되(R10 재검), **나머지 1−w 를 현금이 아니라 QQQ 에 둔다**. 변동성이 높아 TQQQ 를 줄인 날에도 1배 지수 노출은 남겨 R10 의 "노출을 줄이면 2010년대에 선형으로 진다" 교환비를 완화할 수 있는지. 스위치 18 은 TQQQ 쪽에 겹치고, 이탈 중 QQQ 는 (a) 그대로 두거나 (b) 현금으로.

## 데이터·point-in-time
- H0 와 같은 스플라이스 가격(TQQQ·QQQ)·^IRX·비용. t 일 종가까지의 실현 변동성(rv20/rv60) → t 일 목표 → t+1 종가 체결(exec_lag 1), 리밴런스 밴드 5%(매일 비중 조정이라 밴드가 매매 수를 결정 — H0 비용 규약 그대로).
- 다자산 원장(H3 의 `multi_asset_sim`) 으로 TQQQ·QQQ 두 열 목표 비중. B 표본은 전 창(1986~) 가능.

## 그리드 (미리 고정)
목표σ {0.36, 0.45, 0.54, 0.60, 0.72} × 예측기 {rv20, rv60} × 스위치 {없음, 18+이탈 시 현금, 18+이탈 시 QQQ 유지} = **30 조합**. 조합당 ≈ 3초.
G6 이웃: 목표σ 의 그리드 인접 값(±20% 근사) 과 예측기 토글. 플라세보: 목표 비중 DataFrame 의 행 상태 런 셔플 30 seed(연속 비중이라 상태가 많아 거의 그대로일 수 있음 → 그 경우 `shift` 모드로 대체하고 기록), G1~G4 통과 조합만.

## 예상 함정
- R10: 2010 표본에서 MDD 5~6%p 당 배수 0.1 의 선형 교환비. QQQ 로 나머지를 채워도 TQQQ 대비 1/3 노출이라 교환비가 조금 완만해질 뿐.
- 매일 비중 조정 + 22% 세금: 비중을 줄일 때마다 실현 이익 → 연말 세금. 밴드 5% 가 매매를 줄이지만 세후 비율이 세전보다 더 나쁘다(R10 의 세후/세전 0.55~0.87).
- 목표 0.72 는 2010년대 대부분 w=1(TQQQ 실현 변동성 40~60%) 이라 스위치 18 과 같아지고, 0.36 은 평균 w 0.6~0.7 로 수익 1/3 상실.

## 어느 관문에서 떨어질까
G1(중앙 비율 < 1.0). 높은 목표(0.60~0.72)+스위치 조합이 스위치 18(0.93 급) 근처에 그치고, 낮은 목표는 G2 만 통과.
