# H37 — 20일선 재진입 없이 사다리 + 시간 정지 (2026-11-11, 코드 작성 전)

## 가설 한 줄
닷컴 왕복은 20일선 재진입이 만든다. 재진입을 (a) 사다리 매수와 (b) "이탈 뒤 N 거래일 경과 & 종가 > M일선" 로만 하면 왕복이 사라지고, V자는 사다리가 받는지. 다른 점: 재진입 군(보류) 은 20일선을 전제로 했고 이것은 20일선 자체를 없앰. 라벨 없음.

## 그리드 (6 조합)
N {60, 120} × 사다리 {50/65/80, 45/60/75} ⅓ (M=200) = 4 + (N 60, M 50) × 두 사다리 = 2. G6 이웃: N 토글·사다리 교체. 플라세보 런 셔플 30(3 관문 이상).

## 예상 함정
- 2018-12 이탈 뒤 1/3 만 들고 60~120일 뒤(2019-03~05) 재진입 → 2019 상승의 절반 놓침. 2020-03 은 사다리 2/3 + 200일선 위 조건이 2020-06 에야 → V자 일부 놓침.
- 닷컴: 재진입이 200일선 위(2003-05) 까지 없어 왕복 0 → B 좋아질 것.
