# H18 — 직전 실현 L\*=μ/σ² 로 배수 고르기 설계 (2026-11-11, 코드 작성 전)

## 가설 한 줄
분기 첫 거래일에 직전 N년 ^NDX(QQQ 스플라이스) 일간 수익률로 L\* = μ_연 / σ²_연 을 추정해 L\* > hi → TQQQ, lo~hi → QLD, < lo → QQQ 를 다음 분기 동안 보유(± 스위치 18 을 고른 자산에). 다른 점: R10·R28 은 σ 만 썼고, H11 은 2× 를 고정 — μ 추정을 넣은 배수 선택은 미검증. 기존 레버 ETF 보유라 §4 허용.

## 데이터·point-in-time
QQQ 스플라이스(1985~) 수익률로 분기 시작 전날까지 추정. QLD 스플라이스(H11)·TQQQ·비용·창 묶음은 H0. 다자산 원장.

## 그리드 (8 조합)
