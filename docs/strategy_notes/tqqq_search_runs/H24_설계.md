R42: 공포일(큰 갭·큰 음봉) 에 팔면 반등을 놓친다. 스위치 18 의 이탈 조건이 켜진 날이 요동치는 날(QQQ |당일 수익률| ≥ r 또는 |갭| ≥ r) 이면 이탈을 미루고, 조용한 날(둘 다 < r) 종가에 이탈. 최대 d 거래일까지 미루고 그래도 조용한 날이 없으면 그냥 이탈(안전장치). 재진입 20일선 그대로. 다른 점: 문턱(H1)·주기(H12)·재진입(H7/H14) 이 아니라 **이탈 체결일의 성격**.
