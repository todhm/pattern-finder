# H42 — 두 단계 이탈 (2026-11-11, 코드 작성 전; R58 후속)

## 가설 한 줄
이탈을 한 문턱(−18%) 이 아니라 두 단계 — 200일선 아래 & 낙폭 ≥ dd1 이면 보유를 f 로 줄이고, ≥ dd2 면 0 — 로 나누면 문턱 하나의 운(15·21 탈락, 18·24 통과) 이 둔해지는지. 재진입(20일선 → 100%)·사다리(50/65/80 ⅓, 현금/부분 상태에서) 는 그대로.

## 그리드 (5 조합)
(dd1, dd2, f) ∈ {(15, 21, ½), (12, 18, ½), (18, 24, ½), (15, 21, ⅔ 남김), (15, 21, ⅓ 남김)}. G6 이웃: dd 쌍 인접·f 토글. 플라세보 런 셔플 30.

## 예상 함정

- 첫 단계가 −12~−15% 면 2015·2018-10 조정에서 절반을 팔아 휩소 비용.
