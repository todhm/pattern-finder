# H14 — 약세장 길이에 따른 재진입 속도 설계 (2026-11-10 저녁, 코드 작성 전; H7·H12 재진입 가설군 3번째)

## 가설 한 줄
이탈은 스위치 18 그대로. 재진입은 **그 약세가 얼마나 오래됐나**로 가른다: 200일선 아래 체류(이탈 시점부터 센 거래일) 가 L 미만이면 빠른 재진입(20일선), L 이상이면 느린 재진입(50일선 또는 월말 20일선 판정). H7(전 구간 하나의 속도) 과 H12(전 구간 월말) 의 관찰 — 짧은 조정은 빠른 재진입이 좋고 긴 약세장은 느린 재진입이 좋다 — 를 point-in-time 으로 결합.

## 데이터·point-in-time
H0 와 동일. 체류 일수는 이탈 뒤 매일 세므로 사후 정보 없음.

## 그리드 (6 조합)
L {60, 120, 180} 거래일 × 느린 모드 {50일선, 월말 20일선}. 기본 비교 = 스위치 18. G6 이웃: L 인접값·모드 토글. 플라세보 런 셔플 30 seed(G1~G4 통과 시).

## 예상 함정
- 2022(약 10개월 약세) 는 L=60·120 에서 '긴 약세' 로 분류돼 2023-01 재진입이 50일선/월말로 늦어진다 → A-10 2013~2014 시작 창 손해. 2020-03 은 짧아 변화 없음.
- 2000~02 는 긴 약세로 분류되나 스위치 18 의 2001·2002 재진입 휩소(9회) 중 몇 개만 걸러진다.

## 어느 관문에서 떨어질까
G1. 세 번째 G1 탈락이면 §2-7 로 재진입 가설군(H15·H16) 보류.
