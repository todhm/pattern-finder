# H1 — 거시 레짐 × 스위치 18 (이탈 문턱 조절) 설계 (2026-11-10, 코드 작성 전)

## 가설 한 줄
스위치 18 의 이탈 문턱(52주 고점 대비 낙폭)을 거시 합성 점수로 바꾼다 — 거시가 위험이면 더 얕은 낙폭(−10~−15%)에서 먼저 나가고, 건강하면 더 깊은 낙폭(−18~−24%)까지 버텨 2011·2015·2018 류 기술적 조정의 휩소를 줄인다. 재진입(QQQ 20일선 위)·200일선 조건·다음날 체결은 그대로. R11(경보를 이탈 **조건**에 넣음 → 휩소 2~3배)과 다른 점: 경보가 이탈을 만들지 않고 **문턱만** 옮긴다. 거시가 위험이어도 200일선 아래 + 낙폭이 있어야 나간다.

## 데이터·point-in-time
- 가격: H0 와 같은 `tqqq_qqq_spliced_1985_2026-10-24.parquet`(신호 = QQQ 스플라이스 열), 현금 ^IRX.
- 거시(FRED 무키 CSV, `FredCsvAdapter`): T10Y3M(1985~, 금리커브 `score_yield_curve` 역전=위험, +1일), BAA10Y(1986~, 신용 스프레드 `score_credit_spread` 200일 평균 위=위험, +1일 — BAMLH0A0HYM2 는 FRED CSV 가 2023 이후만 주어 참사_조기경보 와 같이 BAA10Y), VIXCLS(1990~, `score_vix` 21일 평균 ≥25 =위험, +1일), UNRATE(`score_sahm_rule` ≥0.5 =위험, 발표 지연 40일). `macro_regime.composite_score` 동일 가중, 날짜별 **있는 지표만** 재정규화(1985 는 커브+실업, 1990 부터 넷). 점수는 `sweep_results/macro_score_1985_2026-10-24.parquet` 로 고정해 재현.
- 레짐: m < risk_thr → 위험(dd_risk), m ≥ healthy_thr → 건강(dd_healthy), 사이 → 기본 0.18. 모두 전날까지 값.

## 그리드 (미리 고정, 결과 보고 바꾸지 않음)
dd_risk {0.10, 0.12, 0.15} × dd_healthy {0.18, 0.21, 0.24} × risk_thr {0.5, 0.75} × healthy_thr {0.75, 1.0} = **36 조합**. 프로토콜 대기열의 명명 조합 = (0.12, 0.24, 0.5, 0.75). n=200·재진입 20·dd_mid 0.18 고정. 조합당 155 창 ≈ 4초 → 전체 ≈ 3분(§2-1 예비 검사 불필요). 플라세보(런 길이 셔플 30 seed, ≈25초) 는 G1~G4 를 통과한 조합에만 계산(관문은 순서대로).
G6 이웃: 통과 조합의 dd_risk·dd_healthy 를 ±20%(그리드 안 인접 값) 로 바꾼 조합들의 G1·G2.

## 플라세보
H0 와 같은 정의 — 전략 자신의 0/1 목표 비중을 런 길이 셔플(전환 횟수·체류 비율 보존). 거시 점수를 섞는 플라세보는 쓰지 않는다(노출이 달라져 비교가 안 됨).

## 예상 함정
- 위험 레짐에서 −10~−12% 는 dd 10~12% 휩소 계열(R8·deep filter 주석 "절반 이하") — 거시가 위험한 해(2011·2022 초·2025) 에 더 자주 나갔다 들어올 가능성.
- 2020-03 은 거시 점수가 폭락 **뒤** 꺼진다(VIX 21일 평균, Sahm 지연) → 문턱이 안 당겨져 스위치 18 과 같음. 2022 는 신용·VIX 가 1~2월부터 위험 → −12% 에서 먼저 나감(유리).
- 건강 레짐의 −24% 는 2018-12(−23%) 처럼 바닥 직전까지 버티다 나가는 역효과.
