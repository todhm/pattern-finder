# 급등주 소거법 탐색 — 계획 (2026-11-11 시작)

`tqqq_search_runs/` 는 "100% 데이터로 검증되는 규칙" 만 찾았고 결과는 H43 패키지(TQQQ 보유 대비 세후 1.5~1.9배)였다.
이 폴더는 기준을 한 단계 낮춘다: **전부를 기계로 증명하지 못해도, 과거 자료만으로 후보를 좁히는 소거법 + 사람이 마지막에 고르는 방식**으로 TQQQ 보다 훨씬 나은 방법을 찾는다. 단 "소거법대로 걸렀을 때 실제로 어땠나" 는 반드시 백테스트한다.

## 0. 쉬운 요약

1. 하루에 +50%, +100% 씩 오르는 주식(급등 사건)을 최근 2년 미국 전 종목에서 전부 찾는다.
2. 그 주식들이 **오르기 전날까지** 어떤 모습이었는지(가격대, 거래대금, 직전 낙폭, 며칠 전부터의 거래량, 과거 급등 이력…)를 표로 만든다.
3. "이 조건이면 버린다" 를 하나씩 쌓아(소거) 매일 후보를 수십 개로 줄이는 규칙을 만든다.
4. 그 규칙으로 걸러진 후보를 **전부 다음날 시가에 샀다면** 어땠는지 백테스트한다(사람이 고르기 전의 바닥 성적). 같은 기간 TQQQ 와 비교한다.
5. 후보 안에서 사람이 볼 체크리스트(차트·뉴스·공시)를 만들고, 표본 날짜를 블라인드로 뽑아 수동 판정이 바닥 성적을 올리는지 본다.

## 2. 반드시 지킬 것 (TQQQ 탐색에서 배운 것 + 급등주 특유의 함정)

- **미래 정보 금지**: 특징은 사건 전날 종가까지만. 진입은 신호 다음 거래일 시가.
- **생존 편향 금지**: 현재 상장 종목 목록으로 과거를 보지 않는다. 급등 뒤 상폐·−90% 된 종목이 표본에 그대로 있어야 한다.
- **체결 가능성**: 주가 $1 미만·일 거래대금 $1M 미만은 "샀다" 고 치지 않는다. 슬리피지는 왕복 1%(초소형 2%) 를 기본으로 건다.
- **조정가 함정**: 역분할 소급 조정으로 생기는 가짜 가격대, 티커 재사용, 워런트·유닛·우선주를 걸러낸다.
- **분모를 같이 본다**: "급등주의 80% 가 X 였다" 가 아니라 "X 인 종목의 몇 % 가 급등했고 X 를 다 샀으면 얼마였나".
- **플라세보**: 같은 날 같은 수의 무작위 종목(같은 유동성 필터) 과 비교.
- **레버리지 금지**(2026-11-10 사용자 제약) — 현물 매수만. 공매도도 하지 않는다.
- 앞 6년(2017-11~2023-12) 으로 규칙을 정하고 뒤 약 3년(2024-01~2026-11) 은 봉인 — 합격 후보에만 연다.

## 3. 합격 기준 (TQQQ 탐색보다 완화, 그러나 고정)

같은 기간 기준선: TQQQ 보유, QQQ 보유.
- **S1 바닥 성적**: 소거 규칙 통과 후보 전부 동일 금액 매수(비용 포함)의 누적 수익이 TQQQ 보다 높고, 앞·뒤 절반 모두에서 TQQQ 의 0.7배 이상.
- **S2 플라세보**: 무작위 대조 30 seed 의 95% 이상을 이김.
- **S3 운용 가능**: 하루 후보 ≤ 30 개, 후보당 거래대금으로 계좌 1억 원이 들어가고 나올 수 있음.
- **S4 수동 판정**: 블라인드 표본에서 사람이 고른 묶음이 "후보 전부" 보다 나음(이건 증명이 아니라 참고).
S1~S3 를 못 넘으면 기각하고 다음 가설로. 넘으면 뒤 1년(봉인) 확인.

## 4. 가설 대기열

| # | 가설 | 상태 |
|---|---|---|
| S0 | 패널 수집 + 급등 사건(+50%/+100%) 전수 목록, 연·가격대·거래대금 분포 | 진행 |
| S1 | 사건 전날 특징표 + 분모(같은 특징의 비급등 종목) → 단일 특징별 급등 확률·기대수익 | 대기 |
| S2 | 소거 규칙 v1(특징 3~5개) → 후보 전부 매수 백테스트 vs TQQQ·플라세보 | 대기 |
| S3 | "급등 다음날" 연구: 첫 급등(+50%) 뒤 추가 상승 vs 반납 — 급등 **후** 따라 사는 쪽이 전날 맞히기보다 쉬운가 | 대기 |
| S4 | 급등 전 압축(저변동·거래량 마름) / 바닥권 거래량 급증 / 과거 급등 이력 재발 | 대기 |
| S5 | 원인 분류(뉴스·실적·임상) 와 수동 체크리스트, 블라인드 표본 | 대기 |
