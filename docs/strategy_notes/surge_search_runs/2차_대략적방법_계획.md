# 2차 탐색 — 대략적 방법론으로 TQQQ 넘기 (2026-11-13 시작)

1차(S0~S8)는 "소거 규칙 → 전부 매수 → 관문" 을 엄격히 돌렸고 전부 TQQQ 아래였다.
사용자 지시(2026-11-13): **너무 데이터 위주였다. 대략적인 방법론이라도 TQQQ 를 이길 방법을 찾을 때까지 계속. 급등주가 아니어도 된다. 과거 시점 자료만 쓰되, 미래를 예상하는 방식도 괜찮다.**

## 바뀌는 것 / 안 바뀌는 것

| | 1차 | 2차 |
|---|---|---|
| 규칙 형태 | 기계 규칙만 | 뼈대 규칙 + 사람(또는 서술형) 판단, 예측 포함 가능 |
| 합격선 | 관문 전부(무작위 95%·이웃 전부) | **느슨한 후보선**: 개발 구간 계단식(시작일 평균) 배수 > TQQQ, 시작일 과반이 TQQQ 이상, 이웃 칸 과반이 TQQQ 의 0.9 배 이상 |
| 최종 심판 | 봉인 구간 | 그대로 — 후보만 봉인 구간(2024-01~)을 **한 번** 연다. 봉인에서도 TQQQ 이상이어야 "찾았다" |
| 자료 | 생존 편향 없는 패널 | 그대로. 미래 정보 금지, 다음날 시가 체결, 폐지 포함 |
| 금지 | 레버리지·공매도 | 그대로 (TQQQ 보유는 허용) |

판정자가 Claude 인 수동 판단은 "기억으로 과거를 아는" 오염이 있다 → 익명 차트(S7 방식)나 규칙화한 판단만 쓴다.
