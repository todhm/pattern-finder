# 3차 탐색 — 옵션을 섞어 TQQQ 넘기 (2026-11-13 시작)

2차 종료 뒤 사용자 지시(2026-11-13): **"아니면 옵션을 섞는 방법으로 찾아줘."**

## 제약을 옵션에 어떻게 옮겼나

기존 제약은 "레버리지(마진·합성 2×/3×)·공매도 금지, TQQQ 보유는 허용" 이다. 옵션은 그 자체가 레버리지 도구라 아래처럼 옮겼다(내 해석 — 틀리면 알려 주세요).

| 허용 | 금지 |
|---|---|
| 옵션 매수(프리미엄 전액 현금 지불, 잃어도 낸 돈까지) | 마진으로 사기, 현금이 음수가 되는 것 |
| 커버드 콜(가진 주식 수 이하로 콜 매도) | 주식 없이 콜 매도 |
| 현금 담보 풋 매도(행사가 × 수량 ≤ 가진 현금) | 담보 없는 풋 매도 |
| 콜 매수 수량 ≤ 자산으로 살 수 있는 TQQQ 주식 수의 1.25 배(델타 합 ≤ 1) | TQQQ 전액 보유보다 큰 노출 |

## 자료와 채점

- **실제 호가**: Alpha Vantage `HISTORICAL_OPTIONS` 일별 체인(TQQQ·QQQ, 2010-03~). 모형 가격을 쓰지 않는다 — TQQQ 옵션은 변동성이 비싸고 호가 폭이 넓어 모형으로는 결론이 뒤집힌다.
- **체결**: 장 마감 호가. 보수적 = 호가 전부 건넘(살 때 ask, 팔 때 bid), 완화 = 중간값과 호가 사이 절반. **판정은 보수적 체결로.**
- **구간**: 개발 2010-03~2023-12(전반 ~2017, 후반 2018~). 봉인 2024-01~ 은 후보만 한 번(2차에서 남은 예산 1 회 + 옵션 계열 새 예산 2 회 = 3 회, 열 때마다 장부 기록).
- **후보선**: 보수적 체결로 개발 배수 > TQQQ **그리고 > H43**(H43 을 못 넘으면 옵션을 쓸 이유가 없다), 전·후반 모두 H43 의 0.95 배 이상, 이웃 칸(델타·만기 한 칸 옆) 과반이 H43 이상.
- 세전·배당 미포함(1·2차와 같은 자). 옵션 손익은 매년 실현되므로 세후는 더 불리하다 — 후보가 나오면 세후도 본다.

## 결론 (2026-11-13)

옵션을 섞어 H43 을 넘는 방법은 없었다. 파는 쪽은 TQQQ 의 큰 상승을 자르고, 사는 쪽(보호)은 변동성 값을 내며, 콜을 더 사는 쪽은 강세 구간에만 이기는 노출 추가다. 봉인 열람 3차 1/3 사용. 종료 보고는 `2차_종료보고_2026-11-13.md` 의 "3차(옵션)" 절.
