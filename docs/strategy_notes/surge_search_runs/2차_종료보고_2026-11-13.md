# 2차 탐색 종료 보고 — 대략적 방법론으로 TQQQ 넘기 (2026-11-13)

## 한 줄 결론

**TQQQ 를 전 구간에서 이기는 방법은 이미 갖고 있는 H43 패키지 하나다. 종목을 고르는 쪽(급등주·모멘텀·주도주·내부자 매수)에서는 기준을 느슨하게 풀어도 새로 찾지 못했다.** 이유는 단순하다 — 강세장의 TQQQ 는 연 +50% 를 내고, 레버리지 없이 그 속도를 따라간 방법이 하나도 없다.

## 확인된 사실들 (다음에 다시 쓰일 것)

1. 강세장(2010~2017)에서 TQQQ 연 +52%. 가장 좋았던 종목 방법이 연 +16%.
2. 종목 방법이 TQQQ 를 이긴 창은 전부 TQQQ 가 -80% 무너진 해(2022)가 들어 있는 창이다.
3. 소거 4 개(급등 직후 제외·꾸준히 오른 종목·대형 거래대금·단기 모멘텀 금지)와 대형주 모멘텀 집중은 무작위보다 확실히 낫다(1.5~2 배). TQQQ 의 3 배 레버리지를 넘을 크기가 아닐 뿐이다. QQQ 는 꾸준히 넘는다.
4. 묶음 안에서 사람 눈(차트 체크리스트)으로 더 고르는 것은 보탬이 없다(S7·S8).
5. 내부자 군집 매수는 시장이 무너졌을 때만 정보가 있다(S6·L6).
6. H43 이 쉬는 구간은 현금(단기 국채)이 맞다.

## 더 가려면 사람이 정해야 하는 것

- **제약을 푸는 길**: 지금은 "레버리지 금지, TQQQ 만 허용" 이다. 강세장 속도를 올리려면 TQQQ 보다 센 것(SOXL·TECL 같은 다른 3 배 ETF, 개별 종목 2 배 ETF)을 허용해야 한다. 허용하면 "H43 의 뼈대 + 강세 구간에 주도 섹터 3 배" 를 볼 수 있다.
- **목표를 바꾸는 길**: "TQQQ 초과" 대신 "QQQ 초과 + 낙폭 절반" 이면 소거 4 개 묶음(연 +20~26%, 낙폭 -36~-50%)과 대형 주도주 3 종목이 답이 된다.
- **자료를 사는 길**: 폐지 종목까지 있는 실적 예상치·재무 자료(유료)가 있으면 실적 서프라이즈·성장 가속 계열을 편향 없이 볼 수 있다. 지금 가진 자료로는 불가능하다.
- **사람이 직접 판정**: Claude 의 수동 판단은 과거를 기억으로 알아 오염된다. 익명 차트 도구(`surge_manual_cli.py`)는 그대로 쓸 수 있다.

## 3차(옵션) 추가 — 2026-11-13

사용자 지시 "옵션을 섞는 방법으로" 에 따라 실제 옵션 호가(Alpha Vantage 일별 체인, TQQQ 2010-03~·QQQ 2011-03~)로 이어서 봤다. 계획 `3차_옵션_계획.md`.

| 단계 | 무엇 | 결과 |
|---|---|---|
| O1 | TQQQ 옵션 33 가지(커버드 콜·보호 풋·칼라·현금 담보 풋 매도·콜 대체·H43 과 결합) | H43 초과 0/33. 옵션만 쓴 방법은 TQQQ 의 0.03~0.67 배 |
| O2 | QQQ 옵션 29 가지(장기 콜로 3 배 이하 노출·QQQ 풋 보호 등) | TQQQ 의 0.36~0.96 배. 2018~2023 만 이김 |
| O3 | H43 + 전량 보유 중 QQQ 콜 더 사기(노출이 TQQQ 전액을 넘음) | 개발 16/17 칸 H43 초과 → **봉인 탈락**(지정 칸 0.99 배) |
| O4 | O3 를 2001~ 에 모형 가격으로 | 2001~2009 에 H43 의 0.77 배 |

결론은 그대로다: **전 구간에서 TQQQ 를 이기는 것은 H43 패키지뿐이고, 옵션은 그 위에 아무것도 더하지 못했다.** H43 의 "팔고 20일선에 되사기" 가 풋보다 싼 보호이고, 강세 구간 속도를 올리는 옵션 사용법(콜 더 사기)은 구간이 강세일 때만 이긴다.
