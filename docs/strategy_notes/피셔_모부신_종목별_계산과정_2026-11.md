## 읽는 법

각 종목은 같은 12단계로 계산한다.

| 단계 | 뜻 |
|---|---|
| ①② | 주가에서 회사 전체 값(EV)을 구한다 |
| ③④⑤ | 그날까지 발표된 재무제표에서 매출·영업이익률·투자율을 읽는다 |
| ⑥ | 성장이 전혀 없어도 설명되는 가치가 EV 의 몇 % 인지 — 나머지가 "성장에 대한 기대" |
| ⑦⑧ | EV 를 맞추려면 10년 동안 매출이 해마다 몇 % 늘어야 하는지 역산하고, 10년 뒤 매출로 바꿔 본다 |
| ⑨ | 그 성장률로 계산한 가치가 EV 와 같은지 검산 |
| ⑩⑪ | 같은 크기 회사들(모부신 Base Rate Book 표 4) 중 그만큼 해낸 비율 P 를 읽는다 |
| ⑫ | **P < 5% 면 제외**, 아니면 유지 |

선택 규칙: 피셔 15 포인트 통과 종목을 피셔 평균 순으로 세우고, **제외 종목을 건너뛰며 위에서 10개**를 고른다. 그래서 종목이 빠지면 그 아래 순위 종목이 올라와 들어온다.

**정정 (같은 날)**: 처음 계산에서는 ASML 의 매출(유로화 보고)을 달러 시가총액과 그대로 비교했다. 보고 통화를 확인해 기준일 환율로 환산하자 2021년 ASML 은 P 4.5% → 6.6% 로 **제외에서 유지로** 바뀌었고, 5년 판 새 선택 평균은 +15.7% → +30.1% 가 됐다. 아래는 고친 뒤의 숫자다. (모집단에서 달러가 아닌 통화로 보고하는 회사는 ASML·CCEP·FER(유로), PDD(위안) 네 곳.)
