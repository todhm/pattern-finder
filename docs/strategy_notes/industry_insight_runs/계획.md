# 산업 통찰 수동 검증 — 계획 (2026-11-14 시작)

## 왜 다시 하나
앞선 `industry_growth_runs/`(G1~G7)는 "숫자 하나로 산업을 줄 세우기" 였다. 사용자 지시(2026-11-14): **1 차원 데이터 발굴이 아니라, 통찰을 갖고 하나하나 수동으로 검증하는 방법**을 찾을 것.
그래서 이번에는 격자를 돌리지 않는다. 사람이 애널리스트처럼 읽고 판단하는 **절차(체크리스트)** 를 만들고, 그 절차를 과거 시점에 한 건씩 적용해 맞는지 본다.

## 방법
1. **사례 도서관(M0)** — 과거에 실제로 폭발한 산업과, 떠들썩했지만 무너진 산업을 짝지어 모은다. 각 사례의 "직전 시점" 에 공개돼 있던 자료(SEC 제출 재무제표·사업보고서 본문)를 읽고, 무엇이 달랐는지 적는다.
2. **통찰 가설 → 체크리스트(M1)** — 아래 가설 v0 를 사례로 다듬어 질문 목록으로 만든다. 질문은 "그 시점 문서를 보면 답할 수 있는 것" 이어야 한다.
3. **가린 판정(M2)** — 산업 이름·연도·회사 이름을 가린 도시에(산업 구조 카드)를 만들어, 이 대화의 맥락을 모르는 별도 판정자(새 에이전트)가 체크리스트만으로 "살 산업" 을 고른다. 판정 뒤에만 정답(앞 3 년 수익)을 연다.
4. **본문 확인(M3)** — 판정자가 고른 산업은 그 시점 선도 회사의 10-K 본문을 직접 읽어 체크리스트 답을 확인한다(수동).
5. **심판** — 고른 산업의 앞 1·3 년 수익을 ① 전체 평균 ② 같은 수 무작위 ③ 기계 규칙(모멘텀)과 비교. 판정 시점은 겹치지 않게 여러 해.

## 통찰 가설 v0 (도시에를 보기 전에 적어 둠)
G1~G7 에서 "성장률이 높다" 는 것만으로는 안 됐다. 그래서 성장의 **질과 구조**를 묻는다.
| # | 통찰 | 물을 것 | 왜 |
|---|---|---|---|
| H1 | **돈이 벌리는 성장** | 매출이 늘 때 이익이 더 빨리 느는가(증분 마진), 선도 회사가 이미 흑자인가 | 이야기뿐인 성장(적자·증자 의존)과 실제 수요를 가른다 |
| H2 | **공급 규율** | 회사 수가 늘지 않거나 줄고, 상위 몇 곳에 매출이 몰려 있는가. 설비투자가 매출보다 빨리 늘지 않는가 | 진입이 자유로우면 성장의 과실이 경쟁으로 사라진다(태양광·3D 프린터·대마) |
| H3 | **남의 돈이 아닌 제 돈** | 주식 수 증가·증자 유입이 작은가, 영업현금흐름으로 투자를 감당하는가 | 증자로 버티는 산업은 주주 몫이 희석된다 |
| H4 | **미리 잡힌 수요** | 선수금·수주 잔고(이연 매출, 잔여 이행 의무)가 매출보다 빨리 느는가, 재고가 매출보다 느리게 느는가 | 고객이 이미 돈을 걸었다는 증거. 재고 누적은 반대 신호 |
| H5 | **가격 결정력** | 매출총이익률이 오르는 중인가 | 수요 > 공급의 가장 직접적인 흔적 |
| H6 | **아직 덜 알려짐** | 최근 주가가 이미 몇 배 오르지 않았는가, 적자 신규 상장이 몰리지 않았는가 | 모두가 아는 성장은 값에 들어 있다(G1·G4) |
| H7 | **확산 범위** | 성장이 선도 1~2 곳이 아니라 산업의 여러 회사·인접 산업(고객·공급자)으로 번지고 있는가 | 한 회사의 일회성과 산업의 구조 변화를 가른다 |

## 정직성 장치
- 판정자는 모델이라 과거를 안다. 그래서 이름·연도·달러 규모를 가리고(비율·지수화만), 판정 시점을 섞는다. 그래도 완전한 블라인드는 아니다 — 보고서에 그대로 적는다.
- 가설 v0 → v1 수정은 사례 도서관(개발용 시점)에서만. 심판용 시점은 따로 떼어 두고 한 번만 쓴다.
- 봉인 구간(2024-01~)은 여기서도 열지 않는다(최종 후보가 있을 때 1 회).
- 합격선: 심판 시점들에서 고른 산업의 앞 3 년 수익이 전체 평균과 무작위 95 백분위를 넘고, 기계 규칙(같은 카드의 숫자 합산)보다 사람이 낫거나 같을 것.
