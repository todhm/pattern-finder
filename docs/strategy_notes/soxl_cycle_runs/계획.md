# SOXL 사이클 읽기 탐색 (2026-11-13 시작)

사용자 지시(2026-11-13, /loop): **"미래학자가 되어서 어떤 책·어떤 잡지 등을 보면 미래를 예측해서 SOXL 을 최저점에 사서 최고점에 팔 수 있는지, 시장의 흐름을 읽는 방법을 찾아서 검증할 때까지 계속."**

SOXL(반도체 3 배 ETF)을 직접 지목했으므로 "TQQQ 만 허용" 제약을 SOXL 보유까지 푼 것으로 본다(마진·공매도·옵션 노출 추가는 여전히 금지).

## 방법 — "읽는 것" 을 "그때 실제로 읽을 수 있었던 숫자" 로 바꾼다

책·잡지가 미래를 맞혔는지는 사후에 고르면 뭐든 맞아 보인다. 그래서 읽을거리를 **그 시점에 발표돼 있던 자료**로 옮기고, 발표 지연을 두고, 규칙으로 만들어 채점한다.

| 읽을거리(무엇을 보라고 하나) | 옮긴 자료 | 발표 지연 |
|---|---|---|
| 반도체 업계지·증권사 리포트: 메모리 가격, 수출, 재고 | 한국 반도체 수출물가($)·수출금액·전자부품 출하/재고(한국은행 ECOS) | 관측월 말 + 1 개월 |
| SIA/WSTS 월간 매출, SEMI 장비 주문/출하 | 미국 반도체 생산·가동률·생산자물가, 컴퓨터전자 주문/출하(FRED) | 〃 |
| 경기 사이클 책(재고 순환·신용 순환): 금리차, 신용 스프레드 | T10Y3M, BAA10Y, 연방기금금리 | 〃 |
| 기술적 분석서: 추세·낙폭 | SOX 200일선, H43 규칙 | 전날 종가 |
| 사이클 달력(반도체 3~4 년 주기, 재고 순환 40 개월) | 달력 규칙 | - |
| 역발상(잡지 표지·비관 기사) | 직접 자료 없음 → "지표가 나쁠 때 산다" 규칙으로 근사 | - |

한계: 지표는 수정된 최종값이다(당시 발표본 아님). 물가·지수류는 수정이 작지만 생산·주문은 수정된다 → 지연을 0·1·2 개월로 바꿔 민감도를 본다.

## 채점

- 자산: SOXL(2010-03 이전은 SOX 일간 3 배 합성 — 실제 구간에서 합성 ×111 대 실제 ×109, 일수익 상관 0.997).
- 창: 1995~2009 · 2010~2017 · 2018~2023 (개발). **봉인 2024-01~ 은 후보만 한 번**(예산 2 회).
- 넘어야 할 것: ① SOXL 보유 ② SOX 200일선(가격만 보는 가장 단순한 타이밍) ③ **TQQQ H43 패키지**(지금 가진 최선).
- 후보선: 세 창 모두 ②·③ 이상, 발표 지연 0·1·2 개월 모두 유지, 같은 보유 비중·왕복 수의 무작위 신호 95% 초과, 이웃 규칙 과반 유지.
- 세전·현금 이자 ^IRX·비중 변경 비용 0.2%.
