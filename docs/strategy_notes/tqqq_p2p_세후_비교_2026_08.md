# TQQQ + P2P 채권 전략 — 세후 성과 비교 (2026-08)

P2P 법인 이자(연 9%, 월 지급, 1년 만기)를 굴리면서 TQQQ랑 50:50으로
가져가면 어떻게 되는지 확인한 기록. 모든 숫자는 **토스증권 수수료
0.1% + 미국주식 양도세 22%(연 250만 공제)**를 반영한 것.
초기 자본 1억, 실제 TQQQ 데이터 기준. 페이지는 `27_TQQQ_P2P_Bond`.

## 알게 된 것

**1. "이자로만 50:50 맞추기"는 상승장에선 작동을 안 한다.**
16년 동안 채권 이자가 TQQQ 매수로 간 달이 한 번도 없었다.
TQQQ가 너무 빨리 커져서 항상 50%를 넘어 있었기 때문.
결국 이 방식은 그냥 "TQQQ 존버 + 채권 월복리"랑 똑같아진다.
수익은 제일 크지만 2022년에 -80%를 그대로 맞는다.

**2. 진짜 50:50을 유지하려면 팔아야 하고, 팔면 세금이 나온다.**
매도 리밸런싱을 켜면 MDD가 -50%로 줄지만, 매도할 때마다
차익이 실현돼서 세금으로 8.5억이 빠졌다. 그래도 세후 39.8억으로
기존 밴드 전략보다 낫다.

**3. 세금은 매매가 잦은 전략에 제일 아프다.**
밴드+레짐 전략은 세전·무비용으로 돌리면 63억인데, 수수료와
매년 세금 정산을 넣으니 세후 29.5억으로 반토막 났다. 매년
차익의 22%가 복리에서 빠져나가는 게 이렇게 크다. 반대로 매매가
없는 전략은 세금을 마지막에 한 번만 내서 이연 효과를 다 누린다.

**4. 방어가 목적이면 금 바스켓이 답이다.**
Optimal Portfolio 상위 조합(금+달러)들은 수익은 낮아도
MDD -33~35%로 제일 안정적. 잠 편하게 자고 싶으면 이쪽.

## 결론

- 수익 극대화 + 폭락 감내 가능 → 현금흐름 모드 (사실상 존버)
- 균형 → P2P 매도 리밸런싱 (세후 기준 밴드 전략보다 우위)
- 방어 우선 → TQQQ50 + 금 바스켓 + 거시레짐
- 어떤 전략이든 **세전 백테스트만 보고 고르면 안 된다.**
  세금 반영 후 순위가 실제로 바뀌었다.
