# 『위대한 기업에 투자하라』(필립 피셔, Common Stocks and Uncommon Profits, 1958) — 종목 고르는 체크리스트 (2026-11-19)

이 문서는 책이 말하는 **"무엇을 사고, 언제 사고, 언제 팔고, 무엇을 하지 말아야 하는가"** 를 빠짐없이 질문으로 옮긴 것이다.
각 질문마다 ① 책의 뜻 ② 책이 말하는 확인 방법(사실 수집) ③ 이 저장소 검증에서 쓴 증거와 한계 ④ 점수 기준을 적었다.
쉬운 설명판은 `피셔_위대한기업_쉬운설명_2026-11.md`, 1년 검증 결과는 `피셔_15포인트_1년검증_2026-11.md`.

> 표기: **[자동]** = 숫자로 계산 / **[문서]** = 당시 공시(10-K·위임장·8-K)를 읽고 판정 / **[불가]** = 책은 사람을 만나 확인하라고 하지만 과거 시점으로는 재현할 수 없어 기록만 함. **[가정]** = 책에 숫자가 없어 이 검증이 정한 값.

| 2 | **사실 수집(scuttlebutt)** — 경쟁사·고객·납품업체·전직 직원·연구자에게 물어 회사의 실상을 안다 | §2 |

| 6 | **언제 팔까 — 그리고 언제 팔지 말까** | §6 |

## 1. 전제 — 책이 서 있는 자리

- [ ] 단기 등락이나 경기 예측으로 돈을 벌려 하지 않는가? (책: 경기 예측은 "연금술 시대의 화학" 수준. 맞히려 하지 말 것)
- [ ] "싸 보이는 주식"이 아니라 **몇 년 동안 매출과 이익이 업계 평균보다 훨씬 빨리 자랄 회사**를 찾고 있는가?
- [ ] 그 성장이 "운 좋게 유능한(fortunate and able)" 회사인지 "유능해서 운이 좋은(fortunate because able)" 회사인지 구분했는가? 둘 다 좋지만, 어느 쪽이든 **경영진의 능력이 계속 필요**하다.
- [ ] 살 종목 수는 적어도 되는가? (책: 잘 아는 탁월한 회사 몇 개 > 잘 모르는 회사 여럿)

## 2. 사실 수집(Scuttlebutt) — 책이 말하는 확인 방법

책의 방법은 재무제표 읽기가 아니라 **업계의 소문망을 타는 것**이다. 한 회사에 대해 아래 사람들에게 물으면 놀랄 만큼 정확한 그림이 나온다고 한다.

| 누구에게 | 무엇을 묻나 | 이 검증에서의 대체 자료 |
|---|---|---|
| 경쟁사 5곳 | "당신 업계에서 강한 회사·약한 회사는?" (자기 회사 말고 남의 회사는 솔직히 말한다) | **[불가]** — 10-K 의 경쟁 항목(회사가 스스로 쓴 것)으로 일부 대체 |
| 납품업체·고객 | 주문 추세, 대금 지급, 제품·서비스 품질, 영업 직원 수준 | **[불가]** — 10-K 의 고객 집중도·잔고·갱신율 서술 |
| 대학·정부·경쟁사의 연구자 | 연구 조직의 수준 | **[불가]** — R&D 지출·신제품 매출 비중 서술 |
| 업계 단체 임원 | 업계 안의 평판 | **[불가]** |
| **전직 직원** | 내부 사정(단, 원한이 있는지 가려 들을 것) | **[불가]** — 8-K 임원 사임 공시 빈도 |
| 마지막에 **경영진** | 위에서 못 채운 빈칸 (필요한 정보의 절반 이상을 안 뒤에 만날 것) | 10-K MD&A·위임장의 경영진 자기 서술 |

> **이 검증의 가장 큰 한계.** 사람을 만나 듣는 정보는 과거 시점으로 재현할 수 없다. 여기서는 회사가 **스스로 써서 제출한 문서**만 읽는다. 회사 문서는 자기에게 유리하게 쓰이므로, 책이 scuttlebutt 로 얻으려던 "남이 본 그 회사"와는 다르다. 아래 15 포인트 중 사람·조직에 관한 것(7·8·9·14·15)은 그래서 신뢰도가 낮다고 표시했다.

## 3. 무엇을 살까 — 15가지 포인트

판정은 포인트마다 **0~3점** [가정]: 0 = 반대 증거가 있다 / 1 = 약하거나 평범 / 2 = 충족 / 3 = 뚜렷이 탁월. 자료가 없어 판단할 수 없으면 **"모름"**(점수에서 제외하고 개수를 따로 센다).
책은 "15개를 대부분 충족해야 하고, 여러 개가 빠지면 좋은 투자가 아니다"라고만 하고 합산 방식은 주지 않았다. **포인트 15(정직성)는 단독으로 거부권**이다("아무리 다른 것이 좋아도").

### 포인트 1 — 적어도 몇 년 동안 매출을 크게 늘릴 만한 시장 잠재력이 있는 제품·서비스가 있는가?
- **책의 뜻**: 일회성 호황이 아니라 여러 해에 걸친 성장. 해마다 고르게 자랄 필요는 없다(경기·신제품 주기 때문에 들쭉날쭉) — **몇 년 묶음**으로 본다.
- **확인 질문**
  - [ ] 지난 5~10년 매출이 업계·경제보다 뚜렷이 빨리 자랐나? 한두 해의 급등이 전부는 아닌가?
  - [ ] 그 성장이 인수가 아니라 자기 제품에서 나왔나?
  - [ ] 주력 시장이 아직 포화되지 않았나? 다음 몇 년의 수요 근거(잔고, 침투율, 신규 용도)를 회사가 구체적으로 말하나?
  - [ ] 성장이 고객 한두 곳에 매달려 있지 않나?
- **증거** [자동] 매출 3년·5년 연평균 성장률, 최근 4분기 전년 대비 성장, 성장의 고르기(5년 중 성장한 해 수), 영업권 비중(인수 성장 표시) / [문서] 10-K 사업·MD&A 의 시장·수요·고객 집중 서술
- **점수** 0 = 매출 정체·감소 / 1 = 경제 성장 수준(연 ~5% 이하) / 2 = 3·5년 모두 연 10% 안팎 이상이고 근거가 구체적 / 3 = 연 15~20% 이상이 여러 해 이어졌고 시장이 아직 넓다 [가정]

### 포인트 2 — 지금 제품의 성장 여력이 다했을 때 매출을 더 키울 신제품·신공정을 계속 개발하겠다는 경영진의 의지가 있는가?
- **책의 뜻**: 포인트 1 은 "지금", 포인트 2 는 "그 다음". 기존 사업과 **연관된** 분야로 넓혀 가는 연구가 가장 좋다(전혀 무관한 분야에 흩어진 연구는 덜 좋다).
- **확인 질문**
  - [ ] 최근 몇 년 사이 나온 신제품이 지금 매출의 의미 있는 부분인가?
  - [ ] 개발 중인 것이 기존 기술·고객 기반과 이어지나?
  - [ ] 경영진이 5~10년 뒤 매출이 어디서 나올지 말하나?
- **증거** [문서] 10-K 의 제품 로드맵·신제품 서술, 신규 부문 매출 / [자동] R&D 지출 추세
- **점수** 0 = 단일 제품에 머물고 다음 계획 없음 / 1 = 말뿐 / 2 = 연관 분야 신제품이 실제 매출이 되고 있음 / 3 = 신제품이 반복해서 성장의 축이 된 이력

### 포인트 3 — 회사 규모에 비해 연구개발 노력이 얼마나 효과적인가?
- **책의 뜻**: R&D 비용을 매출로 나눈 숫자만 보면 속는다(회사마다 R&D 에 넣는 항목이 다르다). 중요한 것은 **쓴 돈이 매출·이익으로 돌아오느냐** — 연구·생산·영업의 협력, 경영진이 연구를 경기 따라 늘였다 줄였다 하지 않는 것.
- **확인 질문**
  - [ ] R&D 대비 늘어난 매출(또는 매출총이익)이 동종 업계보다 큰가?
  - [ ] 불황에도 R&D 를 급히 깎지 않았나?
  - [ ] 방위·정부 과제 위주가 아닌가(수익성이 낮고 남의 것이 된다)?
- **증거** [자동] R&D/매출, R&D 의 3년 변화, "3년간 늘어난 매출총이익 ÷ 3년간 쓴 R&D" [가정], 섹터 안 순위 / [문서] 연구 조직·특허·출시 서술. R&D 가 0 인 업종(유통 등)은 "해당 없음"
- **점수** 0 = R&D 는 큰데 매출이 안 따라옴 / 1 = 평범 / 2 = 섹터 중간 이상의 회수 / 3 = 섹터 상위, 꾸준한 투자

### 포인트 4 — 평균 이상의 영업 조직이 있는가?
- **책의 뜻**: "생산·영업·연구는 성공의 세 기둥"인데 영업이 가장 덜 주목받는다. 뛰어난 제품도 팔 줄 모르면 소용없다. 재무비율로는 안 보이고 **경쟁사·고객에게 물어야** 아는 항목.
- **확인 질문**
  - [ ] 고객이 계속 다시 사는가(재구매·갱신·순매출 유지율)?
  - [ ] 영업·유통망을 직접 키웠나, 교육에 투자하나?
  - [ ] 판매비를 쓴 만큼 매출이 느나?
- **증거** [문서] 10-K 의 판매·유통·고객 유지 서술 / [자동] 판관비 증가 대비 매출 증가 / scuttlebutt **[불가]**
- **점수** 0 = 고객 이탈·유통 문제 공시 / 1 = 평범·판단 근거 약함 / 2 = 반복 매출·유지율 근거 / 3 = 업계가 인정하는 영업력의 구체적 증거

### 포인트 5 — 영업이익률이 쓸 만한가?
- **책의 뜻**: 매출이 늘어도 이익이 안 따르면 무의미. **업계 안에서 비교**하고, 가장 좋은 해가 아니라 **여러 해**를 본다. 한계 기업(마진이 가장 낮은 회사)은 호황 때 이익이 가장 크게 늘어 좋아 보이지만 불황에 가장 먼저 무너진다 — 장기 투자 대상이 아니다. 예외: 성장을 위해 **일부러** 연구·영업비를 더 써서 마진이 낮은 젊은 회사.
- **증거** [자동] 최근 12개월·3년 평균 영업이익률, 섹터 중앙값 대비, 매출총이익률
- **점수** 0 = 적자 지속(의도된 투자 설명 없음) / 1 = 섹터 중앙 이하 / 2 = 섹터 중앙 이상 / 3 = 섹터 상위 25% 이고 여러 해 유지

### 포인트 6 — 이익률을 지키거나 높이려고 무엇을 하고 있는가?
- **책의 뜻**: 과거 마진이 아니라 **앞으로의 마진**. 임금·원가는 오른다. 값을 올려서만 버티는 회사는 오래 못 간다 — 새 설비·공정 개선·원가 절감으로 버티는 회사를 찾는다.
- **확인 질문**
  - [ ] 최근 3~5년 마진이 유지·개선됐나?
  - [ ] 그 이유가 가격 인상뿐인가, 효율·규모·제품 구성 개선인가?
  - [ ] 원가 압력에 대한 구체적 계획이 있나?
- **증거** [자동] 영업이익률·매출총이익률의 3년 변화 / [문서] MD&A 의 마진 설명
- **점수** 0 = 마진 계속 하락 / 1 = 유지, 근거는 가격 / 2 = 유지·개선 + 효율 근거 / 3 = 구조적 개선이 여러 해 이어짐

### 포인트 7 — 노사·인사 관계가 뛰어난가?
- **책의 뜻**: 파업이 없다는 것만으론 부족. 이직률, 지원자 대기 줄, 불만 처리 속도, 임금 수준, 경영진의 태도. 좋은 관계는 생산성으로 돌아온다.
- **증거** [문서] 10-K 의 인적 자본 항목(직원 수, 이직·참여도, 노조), 구조조정·파업 공시 / 전직 직원 **[불가]**
- **점수** 0 = 파업·대량 감원·소송 반복 / 1 = 정보 부족·평범 / 2 = 구체적 지표를 공개하고 양호 / 3 = 드물게 강한 증거. **신뢰도 낮음.**

### 포인트 8 — 임원들 사이의 관계가 뛰어난가?
- **책의 뜻**: 승진이 능력이 아니라 파벌·친족으로 정해지면 유능한 사람이 떠난다. 임원 보수가 업계 수준에 맞고 정기적으로 조정되는가. 외부에서 고위직을 자주 데려오면 내부에 문제가 있다는 신호(작은 회사가 급성장할 때는 예외).
- **증거** [자동] 8-K 5.02 항목(임원 선임·사임) 건수 [가정: 최근 3년] / [문서] 임원 재직 기간, 위임장의 보수 구조
- **점수** 0 = CEO·CFO 교체 반복, 갈등 공시 / 1 = 평범 / 2 = 안정된 팀, 내부 승진 / 3 = 장기 재직 + 뚜렷한 내부 육성. **신뢰도 낮음.**

### 포인트 9 — 경영진에 깊이가 있는가?
- **책의 뜻**: 한 사람이 다 하는 회사는 어느 선에서 멈춘다. 권한을 넘겨주는가, 다음 세대가 길러지고 있는가, 경영진이 **다른 의견을 듣는가**.
- **증거** [문서] 임원 명단·경력·재직 연수, 창업자 의존도, 승계 언급
- **점수** 0 = 1인 의존, 후계 없음 / 1 = 평범 / 2 = 부문별 책임자가 서 있음 / 3 = 승계가 실제로 매끄럽게 이뤄진 이력. **신뢰도 낮음.**

### 포인트 10 — 원가 분석과 회계 관리가 얼마나 좋은가?
- **책의 뜻**: 제품별·공정별 원가를 정확히 모르면 어디에 힘을 쏟을지 모른다. 밖에서는 잘 안 보이는 항목 — 책도 "다른 면이 뛰어난 회사는 대개 이것도 괜찮다"고 인정한다.
- **증거** [문서] 10-K 9A 항목(내부통제: 중요한 취약점 여부), 재무제표 재작성, 감사인 교체 / [자동] 부문별 실적 공시 여부
- **점수** 0 = 중요한 취약점·재작성 / 1 = 문제는 없으나 정보 빈약 / 2 = 통제 유효 + 부문·제품별 상세 공시 / 3 = 판단 어려움(대개 2 가 상한) [가정]

### 포인트 11 — 그 업종 특유의, 경쟁사보다 얼마나 뛰어난지 알려 주는 다른 면이 있는가?
- **책의 뜻**: 업종마다 다르다 — 유통은 임차 조건·입지, 어떤 업종은 신용 관리, 어떤 곳은 특허. 단 **특허에만 기대는 것은 약점**이고, 제조 노하우·영업·서비스로 앞서는 것이 진짜 해자.
- **증거** [문서] 10-K 의 경쟁·지식재산·규모 서술, 점유율
- **점수** 0 = 차별점 없음·특허 만료 임박 의존 / 1 = 평범 / 2 = 뚜렷한 우위 하나 / 3 = 여러 겹의 우위

### 포인트 12 — 이익에 대해 단기적 시각인가 장기적 시각인가?
- **책의 뜻**: 이번 분기 이익을 쥐어짜는 회사 vs 납품업체·고객과의 신뢰를 위해 당장의 이익을 포기할 줄 아는 회사. 후자를 산다.
- **증거** [자동] 재투자율((설비투자+R&D)/영업현금흐름), 불황기 투자 유지 / [문서] 경영진의 서술(장기 목표, 가이던스 태도)
- **점수** 0 = 단기 실적 맞추기·투자 삭감 / 1 = 평범 / 2 = 꾸준한 재투자 / 3 = 단기 이익을 희생한 장기 투자 사례가 구체적

### 포인트 13 — 가까운 장래에 성장을 위해 증자를 해야 해서, 늘어난 주식 수가 기존 주주의 몫을 크게 깎지 않겠는가?
- **책의 뜻**: 현금과 차입 여력으로 몇 년의 성장을 감당할 수 있으면 걱정 없다. 증자가 필요해도 그 뒤 주당이익이 충분히 늘면 괜찮다 — 문제는 **자금 계획이 서툴러 반복되는 희석**.
- **증거** [자동] 주식 수 3년 변화, 주식보상/매출, 순부채/EBITDA, 잉여현금흐름, 현금 보유
- **점수** 0 = 해마다 큰 희석 + 현금 소진 / 1 = 희석 연 2~3% 이상 / 2 = 자체 현금으로 성장, 희석 작음 / 3 = 순현금 + 주식 수 감소 [가정]

### 포인트 14 — 일이 잘될 때는 투자자에게 터놓고 말하다가 문제가 생기면 입을 닫는가?
- **책의 뜻**: 어떤 회사도 실패한 신제품·예상 못 한 문제를 겪는다. 그때 **숨기는 경영진의 회사는 사지 않는다.**
- **증거** [문서] MD&A·위험 요인에서 나쁜 소식을 구체적 숫자로 말하는지, 실적이 나빴던 해의 서술 태도
- **점수** 0 = 문제를 뭉개거나 뒤늦게 드러남 / 1 = 상투적 / 2 = 나쁜 점을 구체적으로 설명 / 3 = 스스로 실수를 먼저 밝힌 사례. **신뢰도 낮음.**

### 포인트 15 — 경영진의 정직성에 의문의 여지가 없는가? (**거부권**)
- **책의 뜻**: 경영진은 주주 모르게 이익을 챙길 방법이 무수히 많다(친족 납품, 과한 스톡옵션, 특수관계 거래). **다른 14개가 다 좋아도 이것이 의심스러우면 절대 사지 않는다.**
- **증거** [문서] 위임장의 특수관계자 거래, 임원 보수의 규모·구조, 10-K 법적 절차(증권 사기·SEC 조사) / [자동] 내부자 매매(약한 보조 근거)
- **점수** 0 = 의심할 근거가 있음 → **탈락** / 1 = 거슬리는 점 / 2 = 문제 없음 / 3 = (쓰지 않음 — 정직은 가산점이 아니다) [가정]

## 11. 검증 불가·주의 (기록만)

- scuttlebutt·경영진 면담 — 재현 불가. 회사 문서로 대체한 것은 **"책을 문서로 흉내 낸 판"**이다.
- 판정을 AI 가 한다. AI 는 기준일 이후의 일을 학습했을 수 있다(2025-11 이후 그 회사에 무슨 일이 있었는지). 회사 이름을 가려도 10-K 본문으로 알아볼 수 있어 **기억에 의한 오염을 완전히 막지 못한다.** 그래서 ① 수치만 쓴 점수(AI 없음)와 ② 무작위로 뽑은 대조군을 함께 판정해 비교한다.
- 재무제표는 Alpha Vantage 의 현재 값(일부는 나중에 재작성된 수치)이고, 발표일로 시점을 자른다.
- 1년은 책의 보유 기간(수년 이상)에 비해 짧다. 종목 10개의 1년 수익률은 운의 몫이 크다.
- 책은 1958년 제조업·화학·전자 회사를 보고 썼다. 소프트웨어·플랫폼 회사에 포인트 3·7 을 그대로 대는 것은 해석이 들어간다.
