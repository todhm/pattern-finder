1. 데이터 백필 (alphafolio_data 호출)

대부분의 미국 데이터(OHLCV/재무제표/매크로)는 Alpha Vantage가 한 번 호출로 전체 과거 데이터를 반환하므로 각 버튼을 한 번씩 누르면 백필 완료. 한국 데이터는 KRX에서 일간 단위로 가져옴.

🇺🇸 미국 마스터 데이터 (월 1회면 충분)

🇺🇸 미국 일간 종합 데이터 (13단계 순차)

us_daily, vwap, news, etf, market_index, calculator(지표), indicator_recovery, us_option, option_summary, move_index, fred_macro, earnings_calendar, insider_transactions

🇺🇸 미국 재무제표 / 매크로 / 캘린더

🇰🇷 한국 데이터

추천 백필 순서 (최초 1회)

  1. 미국: Stock Listing → Finnhub Symbol → Stock Basic → DB 파티션 생성
  2. 미국: Full Daily Pipeline (가장 오래 걸림, 1~2시간)
  3. 미국: 재무제표 3종 (병렬, 약 30분~수 시간)
  4. 미국: 매크로 4종 (각 1~2분)
  5. 한국: 일간 종합 → DART 6종

2. 과거 등급 시계열 생성

매 평일마다 run_option1(target_date=d)를 호출해 us_stock_grade / kr_stock_grade에 등급을 채웁니다. 1일당 5~15분 소요 — 1년치(약 252일) 생성 시 21~63시간. 백그라운드 실행 권장.
